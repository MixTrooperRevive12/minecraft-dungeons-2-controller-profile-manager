## 🎯 About

Windows PC utility for Minecraft Dungeons II focused on organizing controller profiles for Xbox, DualSense, Switch Pro, generic XInput devices, and Steam Input setups.

This repository is the release and documentation home for the utility. Downloadable builds are distributed through **GitHub Releases**.

---

## ✨ Main Features

- **Multiple local controller-profile organization**
- **Xbox, DualSense, Switch Pro and XInput profile workflow**
- **Steam Input-oriented profile notes and presets**
- **Quick switching between controller configuration profiles**
